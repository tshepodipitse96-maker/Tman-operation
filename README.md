# My Website

A simple static website project built with HTML.

## Pages

- `index.html` - Home page
- `about.html` - About page
- `service.html` - Services page
- `contact.html` - Contact page
- `enquiry.html` - Enquiry page

## Instructions

1. Open `index.html` in a browser to view the website.
2. Use the navigation links to move between pages.

## Notes

- This project contains only HTML files.
- You can enhance it by adding CSS and JavaScript for styling and interactivity.
